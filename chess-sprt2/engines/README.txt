Put one folder per engine version here. A folder is an engine when it contains an .exe.

  engines/
    v001-baseline/engine.exe
    v002-pst-tweak/engine.exe
    doubled-pawn/              <- optional group folder for variants of one feature
      v012-dp-05/engine.exe
      v012-dp-10/engine.exe

engine.json next to the exe is optional (name, version, parent, tags, notes) and can be
edited on the Engines page. You can also upload engines from that page.
